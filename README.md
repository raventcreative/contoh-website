# contoh-website

Website AIPRENEUR untuk menjelaskan solusi AI bisnis, metode 3M, AIPRENEUR Academy, dan jalur konsultasi WhatsApp.

## Preview lokal

Jalankan `python3 -m http.server 4173` dari folder repositori ini, lalu buka `http://127.0.0.1:4173/`.

Website dibuat dengan HTML, CSS, dan JavaScript tanpa proses build atau dependensi aplikasi.
